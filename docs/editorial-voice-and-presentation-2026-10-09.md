# 角色稱呼與閱讀呈現｜2026-10-09

## 角色寫法建議：供討論，本輪未批次改寫正文

問題不只在「行動者」難懂，也在敘事中不斷換主詞：人、帳號、模型、平台與調查者容易混在一起。建議固定第三人稱導讀；每次換角色、開始新段落或切換工作線，重新交代主詞。

| 角色 | 一般讀者較直觀的稱呼 | 應交代的工作 |
| --- | --- | --- |
| 指定任務的人 | 使用 Claude 的人／這名使用者／這批帳號的使用者；確知團隊再稱團隊 | 選目標、提供材料、設定立場、安排執行 |
| AI 工具 | Claude／這個 AI 工具 | 翻譯、改寫、整理、編程或執行來源確有記載的步驟 |
| 報告與平台提供者 | Anthropic／Anthropic 報告團隊 | 表示看到什麼、評估身分或成果、封禁自身服務帳號 |
| 事件涉及的對象 | 被蒐集資料的人／被鎖定的網站／遭入侵的服務／收到內容的讀者 | 依事件進度區分目標、確有損害的對象及未確認的受眾 |
| 發布或中間服務 | 發布平台／轉接服務／資料供應商 | 交代它是渠道、處理資料的一方，或實際遭入侵的一方 |
| 本站 | 本站編者 | 在獨立區塊提出解讀、類比與條件式推演 |

「某個來自某國的使用者」雖然直觀，卻容易混入國籍、所在地或政府關係。依來源分別寫「使用中文」「可能位於中國」「來源評估與某機構有關」。不能從語言推出國籍，也不能把多個帳號改寫成相同數量的人。

不把 Anthropic 改稱「本公司」。本站不是該公司的官方中文報告；第一人稱「我們」容易使來源觀察與本站判斷混在一起。只有清楚標明的原文引述，才保留來源的第一人稱。第二人稱「你」適合放在編者建議與操作提示。

### GTG-54004 的稱呼示範

> Anthropic 在報告中記載，一名身分未明的 Claude 使用者，先指定要宣傳的肯亞政治立場，再要求 Claude 每批寫五十則不同說法。這名使用者決定訊息方向，Claude 負責改寫。來源看到多個帳號協同分享，但未確認誰委託、誰付費，或讀者是否被說服。

示範重點是明確主詞與分工；未套用到文章，亦不表示完成新一輪來源查核。若採用，可先在一般使用者、疑似政府關聯、第三方轉接服務三種案例試寫，再決定是否擴展。
