# 實作計畫與範圍

2026-09-12，依已確認規格與案例數修正實作。

1. Phase 1：Astro、TypeScript、MDX 靜態網站與目錄。
2. Phase 2：reports、cases、glossary、topics、pages Content Collections。
3. Phase 3：全站 layout、首頁、報告列表、專題、完整案例索引、個案、概覽、主題、術語、方法、About、權利說明。
4. Phase 4：WhatIsThis、EvidenceBoundary、EditorObservation、Term、SourceReference、CaseMetadata、UpliftSummary。
5. Phase 5：三篇十三段待編輯 MDX 模板；其餘索引項目建立來源索引頁。
6. Phase 6：章節、地區、actor type、台灣相關性、深度導讀、主題篩選；無 JavaScript 仍顯示完整列表。
7. Phase 7：固定 lockfile、建置 CI、資料與內部連結驗證、靜態子路徑支援。
8. Phase 8：README、CONTRIBUTING、METHODOLOGY、CONTENT_LICENSE、差異與內容狀態文件。

固定計數：43 主要案例、1 內嵌補充案例、44 索引項目。固定九個選案與十三段模板。未知資料保留 null／unknown，不自行產生研究正文。先本機 preview，正式部署與遠端公開留待 G 檢查。
